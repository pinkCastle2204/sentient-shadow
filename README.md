# Sentient Shadow

> Featuring AI/ML powered dynamic NPC engine




## Overview

Sentient Shadow is a story-driven 2D top-down RPG built in Godot. Unlike traditional RPGs with scripted companions or enemies, the game features an adaptive AI rival whose personality and decisions evolve according to the player's actions throughout the playthrough.

Every important decision affects the rival's behavior, relationships, quest outcomes, and ultimately the ending of the game.

>This project is currently under active development.
